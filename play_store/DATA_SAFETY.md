# Google Play Store Data Safety Questionnaire Declarations

## Overview
Aura Wallpapers does NOT collect, sell, or share personal user data. All catalog discovery and wallpaper downloads are anonymous.

### Security Practices Declared in Console
1. **Data in Transit:** All network requests and asset downloads use encrypted **HTTPS (TLS 1.3)** with cleartext HTTP disabled in `network_security_config.xml`.
2. **Account Deletion:** Not applicable as user accounts are not required to access the application.
3. **Data Protection Law Compliance:** Complies with GDPR and CCPA privacy standards.
